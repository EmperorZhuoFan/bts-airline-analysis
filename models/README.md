# Models

This directory is reserved for trained machine learning models and model artifacts generated by the project.

## Structure

```text
models/
└── trained model artifacts
```

## Purpose

The directory provides a dedicated location for storing reusable model artifacts separately from the source code.

The project currently develops two machine learning components:

### Supervised Learning

Flight-level classification models including:

* Logistic Regression
* Decision Tree
* Bagging
* Random Forest
* AdaBoost
* Gradient Boosting

### Unsupervised Learning

Airport-level K-Means clustering based on operational characteristics.

## Model Lifecycle

```text
Data
  ↓
Feature Engineering
  ↓
Model Training
  ↓
Hyperparameter Tuning
  ↓
Evaluation
  ↓
Trained Model Artifact
  ↓
models/
```

Model artifacts should only be added when they are intentionally saved for reuse or deployment.

Training methodology and evaluation procedures are documented in:

* [`../docs/methodology/methodology.md`](../docs/methodology/methodology.md)
